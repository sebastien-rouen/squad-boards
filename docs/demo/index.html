    Scénario pas à pas

      Comment c'est fait en deux minutes, sans montage

      1. 📝

        Scénario JSON

        Une liste d'étapes lisible : aller à une vue, cliquer, glisser une carte, sous-titrer, mettre en lumière, poser un carton de chapitre. Versionné à côté de la vidéo.

        { "drag": { "from": ".ticket-card", "to": ".column-cards" } }
      2. 🎭

        Playwright joue, Chrome filme

        Chromium rejoue le scénario sur une instance de démo (données fictives) et livre chaque image en 1080p. Un calque dessine le curseur, les bulles, les tracés, les bandes noires, les transitions.

        Page.startScreencast · 1920×1080
      3. 🎙️

        Voix off locale

        Chaque sous-titre est lu par Piper (synthèse vocale sur le serveur, aucun service cloud), calé à l'instant où il s'affiche, puis mixé en AAC.

        piper · fr_FR-siwis
      4. 🎞️

        ffmpeg assemble

        Images à cadence fixe, H.264 crf 28, démarrage rapide, poster WebP. Chapitres horodatés pour ce lecteur, qui s'ouvre sans serveur, en double-clic.

        libx264 · aac · libwebp

      ⚖️ Poids pour une minute

      Extrapolé depuis les démos de ce dossier · GIF estimé pour comparaison

        Le MP4 se lit partout (<video autoplay muted loop>). Le WebP animé n'a de sens que pour une boucle de 5 à 10 s. Le GIF, jamais.

        🫥 Données fictives, floutage, textes factices

        Une démo se filme d'abord sur une base de démo (rien à cacher). À défaut, chaque scénario dit ce qu'il floute (blur), ce qu'il remplace (fake) et pour qui (audience).
