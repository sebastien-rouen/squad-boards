🪞 Le parallèle

Les deux colonnes partagent le même langage (accent latéral, bandeau teinté) : on lit « voici le cap du trimestre, voici la tranche de ce sprint ».

📱 Responsive

2 colonnes ≥ 720 px, empilées en dessous (PI sous le sprint). Aucune scroll horizontale.

🚩 État vide

Si l'équipe du user n'a aucun objectif PI, un encart pointillé le signale explicitement + action « Définir ».

🎨 Cohérence

Score, barre d'atteinte (cible 80%), badges Commis/Stretch, BV — repris tels quels du composant actuel.
