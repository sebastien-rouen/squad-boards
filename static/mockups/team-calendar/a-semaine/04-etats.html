Parti pris UX

  • Un état = une cause + une action : « partager avec tous les détails », « relier un agenda », « réinitialiser les filtres ».
  • Périmé n'est pas bloquant : un agenda d'hier reste utile ; on le dit, on ne le cache pas.
  • Le masqué reste visible : Lion est occupé, on ne sait juste pas à quoi — l'information de charge demeure.
